# Реестр вычислений метрик

Этот файл — реестр всех вычислений метрик продукта: что вычисляется, где в коде и какая формула используется сейчас. Колонку «Что должно быть» заполняет продукт (Даша) — краткой математической записью, по одной формуле на строку. Разработчики затем выверяют вычисления по этому файлу и пишут тесты.

Пайплайн в одну строку: игра (attempts) → `computeSessionScore()` (скор одной сессии) → два потребителя: `getMetricScores()` (админские 11 метрик, страница /metrics) и `getUserMetricScores()` (пользовательские 6 метрик, донат на /home).

## Пользовательский донат (/home)

Пользовательские метрики считает `getUserMetricScores()` — 5 прямых метрик из `user_metrics` + композитная memory. Прямые user-фидеры memory (тест «Слова и повторы», упражнения «Цепочка слов», «Найди пару», «Повторы в ряду») НЕ участвуют в прямом расчёте: memory строго композитная, их вклад идёт только через админские гранулированные метрики (working/short/long_memory).

Примечание: рекомендации на /home (`getRecommendations`, `src/lib/shared/metrics.ts:171`) и страница /metrics считаются по АДМИНСКИМ скорам (`getMetricScores`).
